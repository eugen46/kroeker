2. Хостинг и серверные журналы

Сайт размещён на GitHub, Inc. / GitHub International Limited через сервис GitHub Pages. При открытии сайта GitHub как хостинг-провайдер автоматически обрабатывает технически необходимые серверные журналы, которые передаёт ваш браузер: IP-адрес, дата и время запроса, запрошенная страница, referrer-URL, тип браузера и операционная система. Эта обработка технически необходима для работы сайта (законное основание — ст. 6(1)(f) GDPR, законный интерес в безопасной и работоспособной эксплуатации). Подробности об обработке данных GitHub — в GitHub Privacy Statement.

GitHub, Inc. зарегистрирован в США. Для передачи персональных данных в США GitHub по собственным данным опирается на EU-U.S. Data Privacy Framework (DPF) и его расширения для Великобритании и Швейцарии (проверено в июле 2026 года — владельцу сайта следует периодически перепроверять актуальность).

3. Cookies и локальное хранилище

Сайт не использует собственные трекинг-cookies. В локальном хранилище вашего браузера (localStorage) сохраняются только технически необходимые значения: выбранный язык, выбранная тема оформления (светлая/тёмная) и статус согласия на cookies. Эти данные не покидают ваше устройство и никому не передаются. Для такого технически необходимого хранения отдельное согласие не требуется (§ 25 Abs. 2 Nr. 2 немецкого закона TDDDG).

4. Google Analytics

Сайт использует Google Analytics — сервис веб-аналитики Google Ireland Limited (Gordon House, Barrow Street, Dublin 4, Ирландия; материнская компания Google LLC, США). Google Analytics загружается только после вашего явного согласия через cookie-баннер (правовое основание — ст. 6(1)(a) GDPR, § 25 Abs. 1 TDDDG). Без согласия передача данных Google не происходит.

При наличии согласия IP-адрес сокращается перед обработкой (анонимизация IP, параметр anonymize_ip). Google Analytics устанавливает собственные cookies для распознавания повторных посещений. Для передачи данных в США Google по собственным данным также опирается на EU-U.S. Data Privacy Framework.

Вы можете отозвать согласие в любой момент через ссылку «Настройки cookies» в подвале сайта — обработка данных при этом прекращается.

5. Шрифты

Шрифты сайта (Inter, Spectral) раздаются с самого сайта. Соединение с Google Fonts или другими внешними сервисами шрифтов не происходит, данные третьим лицам при этом не передаются.

6. Интерактивная карта (OpenStreetMap / Leaflet)

Библиотека карт Leaflet раздаётся с самого сайта. Однако при открытии страницы карты тайлы (сегменты изображения карты) загружаются напрямую с серверов OpenStreetMap Foundation (tile.openstreetmap.org); при этом ваш IP-адрес передаётся OpenStreetMap Foundation. Это технически необходимо для отображения запрошенной вами карты (законное основание — ст. 6(1)(f) GDPR, законный интерес в предоставлении запрошенной функции). Сведения об обработке данных OpenStreetMap — в политике конфиденциальности OpenStreetMap Foundation. Сами картографические данные распространяются по лицензии Open Database License (ODbL), © OpenStreetMap contributors.

7. Форма контакта и email

Форма контакта на сайте только готовит письмо в вашей собственной почтовой программе (mailto-ссылка). Введённые вами данные никогда не передаются и не сохраняются на сервере этого сайта — у этого статического сайта нет собственной серверной обработки данных формы. Только когда вы сами отправите подготовленное письмо из своей почтовой программы, данные будут переданы на email владельца сайта; эта передача регулируется условиями вашего собственного почтового провайдера.

Сайт не встраивает платёжные виджеты. Кнопки PayPal, Ko-fi и ЮMoney — это обычные ссылки, ведущие на соответствующий внешний сайт. Только если вы совершите там какое-либо действие, эти сервисы обработают ваши данные согласно собственным политикам конфиденциальности: PayPal, Ko-fi, ЮMoney. Поддержка через эти сервисы — добровольное частное пожертвование владельцу сайта, а не налогово вычитаемое пожертвование, поскольку у проекта нет соответствующего официального некоммерческого статуса.

По GDPR вам принадлежат следующие права: на доступ к данным (ст. 15), на исправление (ст. 16), на удаление (ст. 17), на ограничение обработки (ст. 18), на переносимость данных (ст. 20), а также право на возражение против обработки (ст. 21). Для этого обратитесь по указанному выше email или используйте в форме контакта вариант «Исправление». У вас также есть право подать жалобу в надзорный орган по защите данных, в частности в стране вашего постоянного проживания. Конкретный надзорный орган, отвечающий за владельца сайта по месту его жительства в Германии, будет указан здесь после подтверждения адреса.
